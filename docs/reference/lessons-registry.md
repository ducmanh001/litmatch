## Registry maintenance

- An `active` row must link current guard/test evidence. Use `monitoring` when implementation
  evidence exists but an effectiveness or regression test is still missing, and name that gap.
  If cause or prevention is still unknown, keep a dated `proposed` record near the investigation
  instead of adding a confident registry entry.
- Link to the specific canonical rule rather than duplicating it. When a lesson requires a durable
  architecture decision, create/update an ADR under [`docs/adr/`](../adr/README.md).
- During incident follow-up, record observed impact separately from inferred impact and never add
  customer or secret data here.
